Tier coverage of GEO-linked papers¶

Question (#141, map #136): on a random sample of the store's PMIDs, how many papers can each download tier serve? Tiers: the PMC bucket, a host pdf_url from OpenAlex, OpenAlex's own paid copy. Builds on PMC routes and OpenAlex downloads.

All probes ran on 2026-11-07 with no account, no key and no email. Each number is measured (counted on a live reply) or inferred (scaled or combined from measured fractions). Intervals are 95% Wilson intervals; a scaled count is the fraction times the stratum size. The scripts are in tier-coverage/; the sample seed is 20261107.

Answer¶

  • The PMC bucket gives 81% of PMIDs their XML and 68% a PDF. Stratum A is 77,674 PMIDs. All 300 sampled were in the bucket; 83% [79–87%] had a PDF, about 64,700 papers (measured, scaled).
  • The XML-only papers are author manuscripts. 16% [12–21%] of stratum A are manuscripts with no open-access flag; none of the 48 sampled had a PDF in the newest version (measured).
  • OpenAlex knows nearly every paper outside the bucket: 98% of stratum B and 99% of stratum C, nearly all with a DOI (measured).
  • A host pdf_url exists for about half of B and 40% of C (measured), but a script gets a PDF from only 19% [14–26%] of those links. Most publisher links return a 403 bot check (measured, 150 links). So host links add about 1,500 PDFs over B and C (inferred).
  • bioRxiv is the one host that always served. 15 of 15 links gave a PDF; Cell Press, PNAS, Wiley, Oxford and ASH links gave a bot check every time (measured).
  • OpenAlex's paid copy exists for 54% of B and 39% of C, about 8,000 papers (inferred). It overlaps the host links almost fully: only 24 of 500 B papers and none of 500 C papers had a paid copy without a host link (measured).
  • About 3,100 B papers and 6,600 C papers have no tier at all (inferred): no PDF link, no paid copy. In C, 39% [35–43%] are closed access (measured).

Can a script fetch the host link?¶

150 of the 449 B and C works with a non-PMC pdf_url, drawn at random; for each, the link the tier would try first (best_oa_location if it qualifies, else the first in locations). One GET each, User-Agent labdata/0.1, 1 per second, 30 s timeout, redirects followed, no retry. A reply is a PDF when its body starts with %PDF; a 403 page naming a challenge or captcha counts as a bot check (measured).

Coverage by tier¶

Inferred: scaled fractions above, combined in tier order. Host-link PDFs are the stratum's non-PMC pdf_url count times its fetch rate, on the first link only, so a paper with a second working link is missed (an undercount).

Tier A (77,674) B (6,797) C (11,040) All (95,511)
PMC bucket XML 77,674 0 0 77,674 (81%)
PMC bucket PDF 64,700 0 0 64,700 (68%)
Host pdf_url, script gets a PDF n/a ~740 ~730 ~1,470 (1.5%)
OpenAlex paid copy, rest of those with one n/a ~2,930 ~3,580 ~6,500 (6.8%)
Nothing 0 XML; ~13,000 no PDF ~3,100 ~6,700 ~9,800 (10%)

At 100 paid files a day per key, the paid tier's ~6,500 papers take about 65 key-days (inferred, from the OpenAlex note's quota).

Left uncertain¶

  • Whether a second host link in locations would serve when the first did not. Only the first was tried.
  • What the Nature .pdf HTML page is: a consent or login interstitial, or a block.
  • Whether stratum C has papers outside OpenAlex's PMID index under a DOI only; the lookup was by PMID.
  • The 16 low PMIDs: whether they are real GEO links or parse artefacts in the PMID count.
